# 動画/音声 文字起こしスキル

ローカルに保存された動画・音声ファイルを読み込み、話されている内容を
そのまま文字（テキスト）に書き起こすスキル。Gemini（動画・音声を直接理解できる
マルチモーダルモデル）を第一候補に使い、失敗した場合は OpenAI Whisper
（音声書き起こし専用API）にフォールバックする。**要約・翻訳・意訳は行わず、
逐語的な書き起こしのみを行う。**

## 手順

1. ユーザーから対象の動画・音声ファイルのパスを確認する。パスが曖昧な場合は
   ユーザーに確認する。出力に使いたい言語（例: 日本語のまま／英語で出力、など）
   の希望があれば合わせて確認するが、指定がなければ**話されている言語のまま**
   書き起こす（翻訳しない）。

2. 文字起こしスクリプトを実行する:

   ```bash
   # Windows / ローカル手動実行
   powershell -NoProfile -ExecutionPolicy Bypass -File ".claude/skills/video-transcriber/scripts/transcribe.ps1" -InputFile "<動画/音声ファイルのパス>" -OutFile "output/transcripts/<スラッグ>.md"

   # Linux / クラウド自動実行
   python3 .claude/skills/video-transcriber/scripts/transcribe.py --input "<動画/音声ファイルのパス>" --out "output/transcripts/<スラッグ>.md"
   ```

   出力言語を指定したい場合は `-Language "ja"` / `--language "ja"` のように
   ISO言語コード（または `"Japanese"` のような自然言語表記）を渡す。省略時は
   話されている言語のまま書き起こす。

   スクリプトは以下の順で試す:
   - **Gemini**（既定モデル `gemini-2.5-flash`）: Gemini File API に動画/音声を
     アップロードし、処理完了（`state: ACTIVE`）を待ってから文字起こしを生成する。
     動画・音声どちらもそのまま渡せる。
   - **OpenAI Whisper**（`whisper-1`）: Gemini が失敗した場合のフォールバック。
     Whisper API が直接受け付ける形式（mp3, mp4, m4a, wav, webm, ogg, flac 等）
     かつ **25MB以下**のファイルのみ対応。動画コンテナ形式（.mov, .avi, .mkv 等）
     や25MB超のファイルではこのフォールバックは使えない旨がエラーに出る
     （その場合は Gemini 側のエラー原因を解消するしかない）。
     詳しくは後述の「ファイルサイズ・長さの上限」を参照。

   APIキーは環境変数 `GEMINI_API_KEY` / `OPENAI_API_KEY`、なければそれぞれ
   `.secrets/gemini_api_key.txt` / `.secrets/openai_api_key.txt`
   （`.gitignore` 済みのローカル専用シークレット）から読み込む。

3. 生成されたテキストファイルは既定で `output/transcripts/` フォルダの下に保存する
   （ユーザーから別の保存先の指定がない限り、常にこのフォルダに保存すること）。
   ファイル名は `output/transcripts/<入力ファイル名（拡張子なし)>.md`
   の形式にする（例: `output/transcripts/2026-09-06_kaigi-log.md`）。

   スクリプトが自動的にファイル冒頭へ以下の形式のメタ情報コメントを付与する
   （`--no-header` / `-NoHeader` を付けない限り）:

   ```markdown
   <!--
   generated_at: 2026-09-06 10:00
   source: <入力ファイルパス>
   provider: gemini (gemini-2.5-flash) | openai (whisper-1)
   -->
   ```

4. 完了したら、使用したプロバイダ（Gemini / OpenAI どちらで成功したか）、
   保存先ファイルパス、書き起こしの文字数をユーザーに短く報告する。

## ファイルサイズ・長さの上限

**25MBという上限は OpenAI Whisper（フォールバック経路）だけの制約であり、
メイン経路の Gemini はもっと大きいファイルを扱える。**

| 経路 | ファイルサイズ上限 | 実質的なボトルネック |
| --- | --- | --- |
| Gemini File API（メイン） | 1ファイル 約2GB | サイズよりも**再生時間**（コンテキスト長） |
| OpenAI Whisper（フォールバック） | 25MB | サイズそのもの |

- 通常の動画（数十MB〜数百MB）は Gemini でそのまま文字起こしできる。
  25MBを超えているという理由だけで失敗することはない。
- Gemini 側の実質的な制限は再生時間。`gemini-2.5-flash`（コンテキスト100万トークン）の
  目安は、**動画で概ね1時間程度、音声のみなら数時間程度**。これを超える長さの素材は、
  ファイルを分割してから複数回に分けて文字起こしし、結果を連結する。
- 25MBを超えるファイルで Gemini が失敗した場合、Whisper へのフォールバックは効かない
  （サイズ超過でスキップされる）。その場合はエラー内容を見て Gemini 側の原因
  （APIキー未設定・クォータ超過・ネットワーク遮断など）を解消する必要がある。
  どうしても Whisper を使いたい場合は、音声のみを抽出して25MB以下に圧縮してから渡す。

## 注意事項

- 動画ファイルは音声トラックのみを抽出せず、そのままAPIに渡す
  （ffmpeg等のローカル動画処理ツールには依存しない。Geminiが動画を直接理解する）。
- Gemini File API へのアップロードはファイル全体をメモリに読み込んで送信するため、
  極端に大きい動画ファイル（数GB単位）ではメモリ・アップロード時間に注意する。
  実行に時間がかかる場合はユーザーにその旨を伝える。
- 文字起こし結果は書かれている/話されている内容をそのまま書き起こすのが目的。
  要約・意訳・解説を勝手に加えない。ユーザーが別途「要約して」と頼んだ場合のみ、
  書き起こし結果を元に別途要約を作成する。
- クラウド実行環境ではネットワークがプロキシ経由になっており、Gemini / OpenAI
  宛の通信が許可リスト（allowlist）に無いと `403` でブロックされることがある。
  スクリプトはAPIキー未設定・非対応形式・サイズ超過などのエラーを検知した場合、
  リトライを繰り返さずにその旨を報告してタスクを終了する（セッションをハングさせない）。
- `.ps1` ファイルは非ASCII文字（日本語コメント等）を含めないこと。コメント・
  エラーメッセージは英語（ASCII）で統一する（`generate_image.ps1`と同様の理由）。
  `.py` は Python 3 が常にUTF-8として読むため対象外。
